# 0.1.43.6 Alpha · 会话恢复、茶楼与课评更新

发布日期：**2026-10-30**。本次汇总自上次公开版本 **0.1.35.3** 以来 32 次开发交付的最终变化，复用第 207 次交付的版本及编号。

## 更新日志

### 校园服务与身份验证

- 完善校园会话跨进程恢复，使用系统安全存储保护账号绑定的凭据和加密 Cookie 快照，修复部分 Cookie 导入失败中断整批恢复的问题。
- 将额外身份验证统一为原生底部弹出页，支持刷新、取消后重开及浅色、深色主题。
- 改进 WebVPN 登录入口、校园服务会话接续和网络切换后的选路，减少重复认证与无效等待。
- 优化一卡通最近交易读取，调整校车连接预算，修复场馆安全检查页面初始化和重新进入时的加载问题。
- 完善图书馆借阅验证、一次性授权接续及账号切换后的结果隔离。

### 茶楼与图片

- 普通网址及简单 Markdown 链接改用原生正文展示，减少正文持续加载的情况。
- 收藏、订阅列表支持左滑取消，修复重复操作和失败后的状态处理。
- 合并重复资料读取和缓存写入，优化信息流滚动、图片索引及网络状态查询。
- 改善公告慢响应和短暂连接故障的恢复，保留已有缓存与手动刷新。
- 修复有效图片因服务器错误类型标记而被拒绝的问题，改善图片打开、原图交接及返回时的亮度与装饰层显示。

### 课评

- 增加同账号课程目录本地缓存，首次进入优先展示缓存并检查更新，本次运行后续由手动刷新更新列表。
- 滚动期间保留有界摘要预加载，将摘要解析和统计移至工作线程，并逐行更新卡片，减少集中计算与批量状态提交。
- 完善课程数量、摘要缓存、手动刷新、详情与列表隔离及旧请求保护。

### 启动与显示

- 优化冷启动状态恢复、会话选路及重复磁盘写入。
- 修复考试与成绩卡片的旧说明、多个页面的加载指示位置。
- 调整关于页和开发者详情，更新开屏及关于页应用图标的柔和光晕。
- 完善读取诊断与错误分类，便于区分网络、认证和组件初始化问题。

# 0.1.35.3 Alpha · 旦挞与桌面卡片更新

发布日期：**2026-10-19**。本次汇总自上次公开版本 **0.1.33.30** 以来的最终变化。应用现名为“旦挞”，仓库地址及应用标识保持不变。

## 更新日志

- 应用名称统一为“旦挞”，原“树洞”统一为“茶楼”，同步桌面名称、登录、设置、关于及提示文字。
- 新增课表、一卡通、寝室电费和校车桌面卡片，点击可进入对应功能；课表、校车支持半高、方形和大卡片，一卡通、寝室电费支持半高和方形卡片。
- 优化桌面卡片的信息层次、长文字、留白和半高卡片排版，修复校车大卡片文字拥挤及课表无课提示不合理换行。
- 调整校园默认卡片顺序，将一卡通、寝室电费向上放置，保留已自定义的布局；拖动卡片时增加透明度，让下方落点描边清晰可见。
- 校园卡片刷新按钮统一放在右下角，右上角统一为详情箭头；优化按钮与卡片圆角对齐。
- 统一校园卡片与“布局编辑 → 添加”预览的排版，以及未加载、加载中、失败和成功状态，改善长文字、上下间距和底部说明的显示。
- 卡片信息变化时采用局部淡入淡出，正文和底部说明独立过渡，减少文字突然跳变和上下漂移。
- 校园课表半高、方形卡片聚焦一节课程；大卡片按节次、课程名、地点分列对齐，优化长课程名、地点与学期说明之间的间距。
- 优化考试与成绩卡片的无课程提示及数量说明，精简场馆预约等卡片的小字。
- 教务处通知、开发组公告仅保留大卡片；图书馆借书、场馆预约仅保留半高和方形卡片，已有不再支持的尺寸自动迁移。
- 修复食堂排队人数卡片长窗口名称和非供餐时段提示被截断的问题，精简半高卡片说明。
- 校车半高、方形卡片无后续班次时显示简短完整的“已无班次”，保留线路说明。
- 开发组公告改为展示最新一条公告的正文摘要，最多显示四行，底部保留更新时间和其他公告数量。
- 优化教务处通知标题和全应用说明文字的自然换行、行距及常见词语保护，减少完整词语被拆开和零碎短行。
- 优化 GPA 区域的视觉层次，将完整计算规则收纳到“计算说明”弹层；公式采用标准分式、求和、上下标排版，调整符号释义和间距，说明区域使用无边框平面材质。
- 修复茶楼搜索结果未跳转到对应帖子楼层的问题；切换分区后从信息流顶部开始浏览。
- 图片保存接入系统保存许可弹窗，恢复下载图标，优化保存状态过渡，返回图片页时保留缩放和位置。
- 修复一卡通等校园服务重新认证时详情页空白或首次进入不读取的问题，统一认证提示与读取诊断的居中排版。
- 校园相关详情页统一保留顶部刷新操作，移除重复的下拉刷新；修复场馆详情与顶部模糊区域重叠、返回列表位置偏移的问题。
- 修复课表周切换箭头及共用图标的中心对齐，复核返回、更多、刷新和展开图标的深浅色显示。
- 关于页加入鸿蒙开发者信息，完善鸿蒙版本说明和贡献者排版，将相关平台标注调整为 Android；优化第一教学周设置和联系我们的说明。
