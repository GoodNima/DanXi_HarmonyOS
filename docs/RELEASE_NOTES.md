包含校园服务卡片与布局编辑、校区服务、学业与课表、系统日历、树洞、富文本与图片、独立课评、账号设置、明暗主题和脱敏读取诊断。细项与支持条件见 [README](../README.md)。

## 已知限制

- 未签名 HAP 不能直接点开安装；需要适用证书及设备授权，尚未在应用市场发布。
- 当前为 API 26 的 phone 目标，不同手机、旧系统及其他设备类型没有全面验证。
- 真实账号下的全部校园服务仍未逐项覆盖；宿舍用电超时、场馆验证恢复和历史课程完整性等仍需实际条件对照。
